# 썸네일/제목 세트 (CTR 집중)

## A세트 (강한 감정)
- 썸네일 메인: **왕을 묻은 죄**
- 썸네일 보조: 단종 X 엄흥도
- 업로드 제목: **세조가 지우려 한 단종, 엄흥도는 왜 목숨 걸고 움직였나**

## B세트 (미스터리)
- 썸네일 메인: **그 밤, 시신을 거둔 남자**
- 썸네일 보조: 17세 왕의 최후
- 업로드 제목: **단종 사사의 밤, 모두가 침묵할 때 엄흥도는 무엇을 했나**

## C세트 (논쟁 유도)
- 썸네일 메인: **역사는 거짓말했나**
- 썸네일 보조: 실록 vs 전승
- 업로드 제목: **단종과 엄흥도(엄흥동), 사실과 전승을 분리해 다시 본 조선사**

## 디자인 지시
- 좌측: 단종 얼굴 클로즈업(청색)
- 우측: 엄흥도 실루엣+횃불(적색)
- 텍스트 2줄 이내 / 50px 이상 / 그림자 적용
- 상단 구석 작은 배지: `실록 검증` 또는 `역사 미스터리`
